# banana

**توليد الصور داخل Claude Code · بلا وسطاء وبلا تبعيات**
*Image generation inside Claude Code — no middlemen, no dependencies*

مهارة تعطي Claude Code القدرة على توليد الصور وتحريرها عبر نماذج Gemini.
Claude يشتغل **مديراً إبداعياً**: يفهم قصدك، يختار العدسة، يبني البرومبت
الاحترافي بصيغة الخمسة مكوّنات، ثم يولّد. أنت تكتب فكرة، وهو يكتب البرومبت.

---

## المبدأ · The contract

| | |
|---|---|
| **وجهة اتصال واحدة** | `generativelanguage.googleapis.com` فقط. لا شيء غيرها. |
| **صفر تبعيات** | مكتبة بايثون المعيارية وحدها. ولا حزمة، على أي عمق. |
| **صفر وسطاء** | لا خادم MCP، لا حزمة npm، لا `npx -y`. |
| **صفر تتبّع** | لا telemetry ولا تحليلات ولا اتصال بالبيت. |
| **صفر إعلانات** | لا فوتر ترويجي، ولا رابط مجتمع في أي رد. |
| **مفتاحك مفتاحك** | يُقرأ من متغيّر البيئة، ويُرسل لجوجل في **ترويسة** لا في رابط. لا يُكتب في أي ملف إعدادات. |
| **ملف واحد يلمس الشبكة** | `gemini_client.py`. تبي تعرف وين يروح مفتاحك؟ اقرأه وحده. |

**الفوترة تروح لجوجل مباشرة.** ما فيه عمولة ولا وسيط ولا حساب لأحد.

## التثبيت · Install

```bash
git clone https://github.com/hussamalraddadi/banana.git
cd banana
bash install.sh
```

المثبّت ينسخ ملفات محلياً فقط. لا يحمّل شيئاً، ولا يركّب حزماً، ولا يلمس إعداداتك.

ثم المفتاح:

```bash
echo 'export GOOGLE_AI_API_KEY="مفتاحك"' >> ~/.zshrc && source ~/.zshrc
```

أعد تشغيل Claude Code، وجرّب:

```
/banana generate a red cube on a white background
```

### ⚠️ الفوترة شرط لا توصية

**جوجل لا تتيح توليد الصور على الطبقة المجانية إطلاقاً.** صفحة التسعير الرسمية
تكتب "Not available" لكل نماذج الصور. بدون تفعيل الفوترة لن يعمل شيء، وسترجع
الأداة خطأ `FAILED_PRECONDITION`.

فعّل الفوترة من [Google AI Studio](https://aistudio.google.com/apikey)،
**وضع سقف صرف** من لوحة جوجل. هذه الأداة تتتبّع الإنفاق ولا توقفه. جوجل وحدها توقفه.

### الإزالة · Uninstall

```bash
bash install.sh --uninstall
```

تحذف `~/.claude/skills/banana/` فقط. بياناتك في `~/.banana/` تبقى، تحذفها بنفسك
لو أردت.

## الأوامر · Commands

| الأمر | ماذا يفعل |
|---|---|
| `/banana generate <فكرة>` | يولّد صورة. Claude يبني البرومبت بنفسه. |
| `/banana edit <مسار> <تعليمات>` | يحرّر صورة موجودة، مثل إعادة تصميم غرفة من صورتها. |
| `/banana chat` | جلسة إبداعية متعددة الجولات. |
| `/banana batch <فكرة> [عدد]` | تنويعات، بتدوير مكوّن واحد لكل واحدة. |
| `/banana inspire [نمط]` | أفكار برومبتات حسب المجال. |
| `/banana preset` | يحفظ هوية بصرية ثابتة ويعيد استخدامها. **يقبل الأسماء العربية.** |
| `/banana cost` | يتتبّع الإنفاق. |

### تسعة أنماط · Nine domain modes

`Cinema` · `Product` · `Portrait` · `Editorial` · `UI/Web` · `Logo` · `Landscape`
· `Abstract` · `Infographic`

لكل نمط عدسة: المنتج يركّز على الخامات وإضاءة الاستوديو، والسينمائي على الكاميرا
والعدسة، والشعار على البناء الهندسي وقابلية التصغير.

## التكلفة · Cost

**القاعدة: أداة تتبّع تخمّن أسوأ من لا أداة، لأنها تُصدَّق.**

لا سعر مكتوب في الكود. الأسعار في `pricing.json`، كل واحد بعلامة تحقّق وتاريخ.
وحين لا تنشر جوجل رقماً، الأداة تقول **`unknown`** ولا تستعير رقماً مجاوراً.

والحساب من **التوكنز** لا من السعر المقرّب، لأن المقرّب يزيغ:
4K يساوي `2520 × $60 ÷ 1M = $0.1512`، تنشره جوجل `$0.151`، ويكتبه Vertex `$0.15`.
عُشر سنت لا يعني شيئاً على صورة، ويعني مالاً حقيقياً على عشرة آلاف.

### الأسعار المؤكدة · ١٧ يوليو ٢٠٢٦

من [صفحة جوجل الرسمية](https://ai.google.dev/gemini-api/docs/pricing) مباشرة:

| النموذج | 1K | 2K | 4K |
|---|---|---|---|
| `gemini-3.1-flash-image` (الافتراضي) | $0.067 | **$0.101** | $0.151 |
| `gemini-3-pro-image` | $0.134 | $0.134 | $0.24 |
| `gemini-3.1-flash-lite-image` | $0.0336 | غير منشور | غير منشور |
| `gemini-2.5-flash-image` | $0.039 | غير منشور | غير منشور |

**خصم Batch: ٥٠٪ على كل النماذج.**

الفجوات مقصودة: جوجل لا تنشرها، والأداة تقول لا أعرف. التفاصيل في
[`references/gemini-models.md`](skills/banana/references/gemini-models.md).

## ما لم يُتحقّق منه · Not verified

الصراحة جزء من الأمان، فهذه مذكورة لا مخفية:

- **هل `gemini-3.1-flash-image-preview` القديم ما زال يعمل كـ alias؟** صفحات جوجل
  الأحدث (٢٠٢٦-٠٧-٠٩) تستخدم المعرّف بلا لاحقة وتدرجه تحت Stable، وصفحة أقدم
  (٢٠٢٦-٠٧-٠٣) ما زالت تكتب "Preview". هذا البناء يعتمد **بلا لاحقة**. الحسم
  يحتاج نداء API حقيقياً.
- **عدد التوكنز للدقات غير المنشورة** في الجدول أعلاه.
- **كل قيم RPM/RPD/IPM** — جوجل ما عادت تنشرها، وتقول إنها تُقرأ من لوحة AI Studio.

أي رقم غير موجود هنا: لا تخمّنه. الرقم الغلط يُصدَّق ثم يتحوّل فاتورة مفاجئة.
